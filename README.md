# Inclusive Health — Training Module 4

**Role-Based Advanced Practice & Leadership**

This repository contains the browser-based Inclusive Health Module 4 training experience.

## Role tracks

- 4.1 Reception & Patient Access Specialist
- 4.2 Medical Assistant Advanced Clinical Training
- 4.3 Nursing Role Optimization & Advanced Clinical Skills
- 4.4 Provider Onboarding & Clinical Excellence
- 4.5 Management, Supervisory & Leadership Training

The learner’s selected role determines the required track. All other courses remain available for optional cross-training.

## Training features

- All five modules active from the start
- Every course button reads **Begin Module**
- Full curriculum lessons based on the supplied packets
- 20-question assessment per role track
- 80% passing score
- Competency checklist
- Browser-local learner progress
- Printable certificate
- CSV training-record export
- Responsive layout

## Deployment

Designed for static hosting, including GitHub Pages from the repository root on `main`.

## Important

The course content reflects the supplied curriculum. Clinical, regulatory, scope-of-practice, coding, HR, and operational content should be reviewed against current Inclusive Health policy and applicable Washington requirements before being assigned as mandatory production training.
